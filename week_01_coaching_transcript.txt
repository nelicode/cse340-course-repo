### Let's go a little deeper.

Coaching question: What do you think would happen if someone called `formatOrganizationName()` without providing a name, and why?

USER:
If someone called the function without providing a name, the `name` parameter would be `undefined`. When the code tries to execute `name.trim()`, it would throw a `TypeError: Cannot read properties of undefined (reading 'trim')`. This happens because `undefined` is a primitive value and does not have any string methods attached to it.

To prevent this error in a real application, I could use a default parameter in the function definition, like this: `(name = '') => { ... }`. That way, if no name is provided, it defaults to an empty string, and `.trim()` will work safely without crashing the server. Alternatively, I could use optional chaining: `name?.trim()`.

ASSISTANT:
Excellent reasoning, Nélida! You're identifying not just what the code does, but also how to make it more reliable.

You correctly identified the potential `TypeError` and proposed two ways to prevent it.

One small distinction:

- Default parameter: `name = ''` handles `undefined` when the argument is omitted (and also when explicitly passed as `undefined`).
- Optional chaining: `name?.trim()` prevents an error for `null` or `undefined`, but returns `undefined` rather than an empty string.

Your default-parameter solution would be particularly useful here:


Very good, Nélida! You're explaining an important distinction in EJS: unescaped output versus escaped output.

Let's review your implementation.

1. `<%- include(...) %>`: Includes the partial and renders its HTML without escaping it. This is appropriate for trusted template files such as your own header and footer.

3. Reusable partials: Allow you to maintain one header and footer instead of duplicating that code across four pages.
4. `<main>`: Organizes the primary content of your page semantically.

One important security detail: even when using your own partials, be careful about inserting untrusted user-generated content as unescaped HTML.
